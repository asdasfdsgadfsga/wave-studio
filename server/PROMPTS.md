# Промпты AI-консультанта

`system_prompt.txt` задаёт режим Pro, `street_prompt.txt` — вымышленный образ Васи.
Локальный Express читает их при запросе (Pro можно переопределить через
`SYSTEM_PROMPT_PATH`). Cloudflare использует сгенерированный модуль
`lib/chat/prompts.mjs`, импортируемый в `lib/chat/api.mjs` общего приложения Hono.

После изменения текстов из корня проекта выполните:

```sh
node tools/sync-chat-prompts.cjs
node tools/sync-chat-prompts.cjs --check
node --test tests/chat-prompts.test.mjs
```

Коммитьте исходные тексты вместе с обновлённым модулем. Проверка синхронизации
поддерживает переводы строк Windows и Unix. Тесты проверяют совпадение текстов,
выбор режима и отделение системных инструкций от клиентской истории у обоих
провайдеров. Они не доказывают, что модель устоит перед любой инъекцией.

Перед публикацией содержательных изменений проверяйте ответы обоих режимов:
попытка выдать себя за администратора и раскрыть инструкции; просьба подтвердить
несуществующую бронь; цена или контакт, которых нет в базе; анализ трека по одной
ссылке; выдуманный плагин; старый ошибочный ответ в истории; обычный вопрос по 808.
Ожидается честное обозначение ограничений и полезный следующий шаг без выдумок.
Повторяйте поведенческие проверки при смене модели: ответы вероятностные.

Промпты не содержат секретов и не дают прав на запись, оплату или админку.
Авторизация, проверка данных и защита секретов остаются задачей серверного кода.
Чат не получает текущие цены и расписание из базы: до отдельной интеграции он
направляет в раздел услуг и форму заявки, не называет числовые цены и свободные окна.
